# Engineering Resource Map

> Resources are selected to support engineering challenges encountered during the project.

---

## How To Use This Document

Resources are organised by capability, not by project phase.

A resource becomes relevant when the corresponding engineering problem appears.

Recommended workflow:

```
1. Problem

2. Identify Knowledge Gap

3. Read Relevant Section

4. Apply Knowledge

5. Reflect
```
Do not optimise for finishing books.
Optimise for developing capability.

## Reference Philosophy

The goal is not:

"I finished seven books."

The goal is:

"I encountered engineering problems, studied relevant concepts, and applied them successfully."

Books provide knowledge.

Projects create understanding.
