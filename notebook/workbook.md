# Engineering Workbook

> Learn by solving engineering problems.


## How To Use This Workbook

Do not begin with textbooks.

Begin with the engineering challenge.

The workflow:

```
1. Engineering Problem

2. Questions

3. Focused Learning

4. Experiment

5. Implementation

6. Review

7. Reflection
```
